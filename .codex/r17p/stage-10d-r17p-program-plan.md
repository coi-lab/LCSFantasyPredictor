# R17P staged implementation program

| Stage | Objective / inputs | Likely files and producers | Tests / evaluation / write scope | Stop condition → next |
|---|---|---|---|---|
| R17A | Parameterize and evaluate S30 recent form. Canonical player-game history, R17P frozen candidate registry. | `canonical_pit.py`, candidate-only recency builder/state, `fit_s30_v2.py`, new script/tests; Oracle→canonical PIT. | Unit cutoff/fallback/determinism tests; 2024 selection + frozen 2025 validation; candidate artifacts/evidence only, no activation. | no robust portable winner → retain current form, then R17B; pass → freeze state, R17B. |
| R17B | Correct FE all-opponent aggregation and test dedicated Elo/matchup term. Canonical games/series, schedule, frozen R17A form. | `recovered_components.py`, `canonical_pit.py`, dedicated matchup producer/script/tests; Oracle+schedule→PIT. | all-opponent/no-volume/cutoff tests; incremental common-row 2024–25 evaluation; candidate state/evidence only. | producer or incremental gate fails → retain relevant predecessor; pass → freeze components, R17C. |
| R17C | Diagnose and, only if supported, calibrate dispersion. Frozen R17A/B predictions plus labels. | evaluation/calibration script, state format, tests; prediction artifacts→chronological calibration state. | OOS calibration and role diagnostics on 2024–25; no runtime activation. | no compression/OOS pass → identity; otherwise freeze calibration → R17D. |
| R17D | Combine only independently passed components with additive attribution. | candidate adapter, evaluation script/tests; frozen states and PIT frames. | common-row ablation, arithmetic/schema/deterministic tests, 2024–25; candidate evidence. | combination fails → best frozen component set; pass → freeze player model, R17E. |
| R17E | Independently calibrate optimizer conflict penalty. Frozen player model, coach/champion/market/budget lineage. | `lineup_optimizer.py` candidate config, optimizer eval script/tests. | preregistered development grid, frozen later validation plus archive diagnostics; do not touch ladder. | missing lineup lineage or no gain → retain 5.0; pass → R17F. |
| R17F | Prospective shadow validation with no outcome-driven changes. | shadow adapter/export and tests; pre-lock raw inputs. | target-free inference, schema, determinism, monitoring/rollback evidence; archived 2026 diagnostic only after freeze. | any portability/schema failure → repair prior producer; pass → R17G. |
| R17G | Owner-approved portability/cutover. | activation config, schema adapter, runbook, guarded tests. | full gate checklist, rollback rehearsal, focused + regression tests; controlled production activation only. | any gate fails → remain current CE; all pass → activation verdict. |

All implementation stages are AGY-owned. R17A is the first coding node because it is dependency-clean, changes only individual-form candidate construction, and can be evaluated before combining team/matchup signals; it does not require a new team-strength producer or optimizer data lineage.
