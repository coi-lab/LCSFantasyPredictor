# Weekly Refresh Checklist

- Confirm target round and roster-lock timestamp.
- Capture or select the official market snapshot.
- Verify roster aliases, roles, opponents, and prices.
- Resolve the post-transaction budget from account state.
- Run projections with only pre-lock data.
- Confirm accepted experimental features and disabled candidates.
- Run champion recommendations and lineup optimization.
- Export dashboard JSON.
- Assert the new snapshot exists and older snapshots are byte-for-byte
  unchanged unless a historical correction was explicitly requested.
- Inspect the top lineup, alternative lineups, cost, remaining budget, variety
  bonus, conflicts, and representative projections.
- Record commands, artifacts, and limitations.
